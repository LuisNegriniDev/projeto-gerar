# 📦 Processos de Distribuição e Armazenamento

Uma plataforma educacional interativa desenvolvida para apresentar e explorar, de forma prática e dinâmica, os principais processos envolvidos na distribuição e no armazenamento de mercadorias.

O projeto transforma o aprendizado teórico em uma experiência interativa, na qual os participantes podem conhecer etapas logísticas, enfrentar situações do cotidiano profissional e testar seus conhecimentos por meio de desafios.

## 🎯 Objetivo

Demonstrar a importância dos processos de distribuição e armazenamento, destacando como cada etapa contribui para a organização do estoque, a eficiência operacional e a entrega correta dos produtos.

## 🚀 Funcionalidades

- **Conteúdo educativo:** apresentação das principais etapas dos processos logísticos.
- **Eureka — Aprendendo na Prática:** simulação de situações e desafios relacionados à rotina de um centro de distribuição.
- **Level Up — Avaliando a Aprendizagem:** questionário interativo para testar os conhecimentos adquiridos.
- **Next Level — Refletindo sobre o Aprendizado:** reflexão sobre os conteúdos estudados e sua aplicação no ambiente profissional.
- **Sistema de pontuação:** acompanhamento do desempenho durante as atividades.
- **Feedback interativo:** explicações e retornos sobre as respostas dos participantes.

## 📚 Conteúdos abordados

O projeto apresenta sete etapas fundamentais da operação logística:

1. Recebimento de mercadorias;
2. Conferência e endereçamento;
3. Estocagem e armazenamento;
4. Identificação dos produtos;
5. Separação de mercadorias (Picking);
6. Embalagem;
7. Expedição.

## 🛠️ Tecnologias utilizadas

- HTML5 — estrutura da aplicação;
- CSS3 — estilização e responsividade;
- JavaScript — interatividade, lógica dos desafios e sistema de avaliação.

## 💻 Como executar o projeto

1. Faça o download ou clone este repositório:
   ```bash
   git clone https://github.com/SEU-USUARIO/SEU-REPOSITORIO.git
   ```
2. Abra a pasta do projeto.
3. Execute o arquivo `index.html` em seu navegador.

Não é necessário instalar dependências para executar a versão local, desde que o projeto não tenha recebido novas dependências externas.

## 🎓 Contexto acadêmico

Projeto desenvolvido como atividade prática da temática **80 – Processos de Distribuição e Armazenamento**, com foco na aplicação dos conhecimentos teóricos por meio de recursos digitais e atividades interativas.

A proposta é aproximar os participantes de situações reais do ambiente logístico, incentivando o raciocínio, a tomada de decisão e a resolução de problemas.
